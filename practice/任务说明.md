## 背景

美国人口普查数据，预测**一个人的年收入是否超过 5 万美元**。

- 大小：32561 行 × 15 列
- 指标：AUC
- 正例比例：约 24%（`>50K` 的人）

贷款数据和这份数据的业务完全不同，但需要的处理技能一模一样，而且它有几个贷款数据里没有的坑。

## 两个版本的数据，用哪个都行

| 文件 | 说明 | 体检命令 |
|---|---|---|
| `practice/adult.csv` | **推荐先用这个**。带表头，值前后没有多余空格，可以直接读、也能用 Excel 打开 | `uv run python 体检.py practice/adult.csv` |
| `practice/adult.data` | 原始版本，没有表头，每个逗号后面跟了个空格。**比 csv 版多一个坑** | `uv run python 体检.py practice/adult.data --no-header --names-file practice/adult_列名.txt` |

**建议**：先用 `adult.csv` 把主流程走通，做完之后如果想再练一遍，换成 `adult.data` 重跑一次 —— 那个版本会多教你怎么发现"看不见的脏值"。

## 任务

写一个 `practice/preprocess_adult.py`，把这份数据变成能直接喂给模型的数字矩阵。

**产出的文件和接口：**

```python
np.savez_compressed("practice/adult_processed.npz",
                    X_train=X_train, y_train=y_train,   # 训练集
```

要求：
- 自己切 80% / 20%，`random_state=42`，让两边正例比例接近
- 所有特征必须是 `float32`，**不能有任何 NaN**
- 训练集每个特征的均值接近 0、标准差接近 1

**训练可以用你现有的代码。** 把 `train.py` 复制成 `practice/train_adult.py`，只改数据加载那几行，网络结构和训练循环一行都不用动 —— 这正是当初把数据处理和训练拆成两个文件的好处。

## 分数参考

我在同样的切分方式下实测了两个分数，给你当坐标：

| 做法 | AUC |
|---|---|
| 速通版（15 行）+ 逻辑回归 | **0.9093** |
| one-hot + sklearn 梯度提升 | **0.9295** |

所以：

- **0.90 左右**：正常，说明速通版就跑通了，接下来该做特征工程
- **0.91 ~ 0.92**：处理得不错，说明你有几项优化确实起了作用
- **0.93 附近**：接近这份数据的上限了
- **低于 0.88**：某个环节有问题，回去查自检清单和第六步的检查代码

## 这份数据里的坑（先说有几个，不说怎么解）

用 `adult.csv` 的话，你会遇到下面 1~5：

1. 有 3 列把**缺失值伪装**起来了，体检脚本能扫到，但你得自己决定怎么填
2. 有两列**表达的是同一件事**，一个文字一个数字，留哪个？能不能都留？
3. 有一列名字像"体重"，其实含义和大小完全无关，你自己判断要不要留
4. `age`、`hours_per_week` 这些，体检脚本猜的是"数值·离散(偏类别)"，但它们是**连续数字**。想想脚本为什么会猜错，你应该听它的还是听自己的
5. 有一列 91.7% 的值都是 0，剩下 8.3% 跨度极大

换成 `adult.data` 还会多一个：

6. 每个逗号后面跟了个空格，导致所有文字值前后都有空格。它不会让 one-hot 出错，但会让第 1 条的那些 `?` **替换不掉，而且不报错**

## 建议的做法

**第一遍：15 分钟速通版。** 照 [表格数据处理流程.md](../表格数据处理流程.md) 「第六步」那 15 行写，先跑出一个能看的分数。不要一上来就追求完美。

**第二遍：按第四步的装箱表逐项改。** 每改一项，记录 AUC 变化，看哪一项有用：

```
基线（速通版）                        AUC = ?
+ 长尾列取 log                        AUC = ?
+ 那个有顺序的列改成 map               AUC = ?
+ 高基数列改成频数编码                 AUC = ?
+ 加"是否缺失"标记                     AUC = ?
+ 处理掉那个没用的列                   AUC = ?
```

**这样你就在做真正的特征工程了** —— 每次只动一个变量，用验证集 AUC 判断有没有用。
